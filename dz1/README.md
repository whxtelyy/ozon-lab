# ДЗ1 - Консольный таск-трекер

Интерактивная консольная программа для управления задачами на Go. После запуска принимает команды до ввода `exit`.

## Возможности

- Создание, просмотр, редактирование и удаление задач.
- Статусы `planned`, `in_progress`, `canceled`, `done`.
- Автоматическая выдача ID без повторного использования после удаления.
- Сохранение задач в `tasks.json` между запусками.
- Сортировка по дедлайну, затем по ID.
- Фильтрация по статусу и просроченности, поиск по заголовку и пагинация.
- Импорт задач из JSON с пропуском некорректных записей.

## Структура

```text
cmd/tasktracker/       запуск программы
internal/domain/       типы и модель задачи
internal/service/      бизнес-логика
internal/storage/      хранение задач
internal/cli/          команды и вывод в консоль
```

## Запуск

Команды выполняются из `dz1/`:

```bash
go run ./cmd/tasktracker
```

Задачи сохраняются в файл `tasks.json`. После перезапуска программы они остаются в списке.

## Команды

```text
help
add "Подготовить отчет" 2099-10-10
list
list --status in_progress
list --overdue
list --search отчет
list --page 2 --limit 10
get 1
status 1 in_progress
edit 1 --title "Новый заголовок"
edit 1 --deadline 2099-10-20
edit 1 --title "Новый заголовок" --deadline 2099-10-20
delete 1
import ./import.json
exit
```

При создании и редактировании нельзя указывать пустой заголовок или дедлайн в прошлом. Статусы `done` и `canceled` нельзя изменять или редактировать. Для `list` по умолчанию используются `page=1` и `limit=20`; если страницы нет, возвращается ошибка.

## Импорт JSON

Команда `import` принимает путь к JSON-файлу. Поддерживаются два формата.

Массив задач:

```json
[
  {"title": "Задача 1", "status": "planned", "deadline": "2099-10-10"},
  {"title": "Задача 2", "status": "in_progress", "deadline": "2099-10-12"}
]
```

Объект с полем `tasks`:

```json
{
  "tasks": [
    {"title": "Задача 1", "status": "planned", "deadline": "2099-10-10"}
  ]
}
```

Если отдельная задача некорректна, программа показывает ее номер и причину ошибки, но продолжает импорт остальных.

## Тестирование

```bash
gofmt -l .

go build ./...
go vet ./...
```

Unit-тесты покрывают бизнес-логику, хранилище, фильтрацию, поиск, пагинацию и импорт.
