# ДЗ4 - SQL и базы данных

Пять запросов к PostgreSQL: фильтрация, группировка, сортировка, соединение таблиц и подзапросы.

## Файлы

- `setup.sql` - создание таблиц `users` и `orders` и загрузка данных из задания.
- `solutions.sql` - решения пяти задач в порядке условия.

## Запуск

Для выполнения нужен PostgreSQL. Создайте отдельную базу для работы:

```bash
createdb ozon_hw4
```

Из папки `dz4/` выполните:

```bash
psql -d ozon_hw4 -v ON_ERROR_STOP=1 -f setup.sql
psql -d ozon_hw4 -v ON_ERROR_STOP=1 -f solutions.sql
```

`setup.sql` пересоздает таблицы `users` и `orders`, поэтому его следует запускать только в учебной базе. Запросы также можно выполнить через Query Tool в pgAdmin.

## Решения

1. **Долгожитель** - выбираются все пользователи Москвы с максимальным возрастом. На тестовых данных это Борис и Вера (40 лет).
2. **Перепись населения** - количество пользователей по городам с фильтрацией через `HAVING`: Москва - 3, Казань - 2.
3. **Учет трат** - `LEFT JOIN` сохраняет пользователей без заказов, а `COALESCE` заменяет отсутствие суммы на `0`.
4. **Любители музыки** - `DISTINCT` исключает повторяющиеся имена покупателей наушников: Глеб, Егор.
5. **Бюджетный выбор** - подзапрос находит минимальную цену среди заказов дороже 10000, а основной запрос возвращает все заказы с этой ценой. Для тестовых данных это наушники за 12000.

Бонусное задание с реализацией метода на Go не включено: оно необязательное и предполагает наличие отдельного проекта `item` с готовым слоем хранилища.
