# Ozon Lab

Учебный репозиторий с домашними заданиями по Go, микросервисам и базам данных. Каждая работа находится в отдельной папке со своим README.

## Домашние задания

### [ДЗ1 - Консольный таск-трекер](./dz1/README.md)

Консольная программа для управления задачами: создание, редактирование, статусы и удаление. Задачи сохраняются в JSON-файл. Есть фильтры, поиск, пагинация и импорт из JSON.

### [ДЗ2 - Микросервисы и gRPC](./dz2/README.md)

Два сервиса: `product-service` предоставляет информацию о товарах по gRPC, а `cart` работает с корзинами через HTTP. Товары читаются из JSON, корзины хранятся в памяти. Добавлены пагинация товаров, логирование HTTP-запросов и Swagger.

### [ДЗ3 - Тестирование и конкурентность](./dz3/README.md)

Продолжение ДЗ2 с упором на тесты и конкурентную работу. Добавлены unit- и интеграционные тесты, проверка гонок и бенчмарки. Корзины защищены `sync.RWMutex`, а информация о товарах запрашивается параллельно.

### [ДЗ4 - SQL-запросы](./dz4/README.md)

Работа с SQL: фильтрация данных, группировка, объединение таблиц через `JOIN`, сортировка и подзапросы. В папке находятся готовые запросы и SQL-скрипт для создания таблиц с тестовыми данными.

## Запуск

Для ДЗ1–ДЗ3 нужен Go. Для ДЗ2 и ДЗ3 также понадобится `make`; генерация protobuf требует `protoc`, `protoc-gen-go` и `protoc-gen-go-grpc`. Для ДЗ4 используется PostgreSQL.

Команды выполняются из корня репозитория.

**ДЗ1:**

```bash
cd dz1
go run ./cmd/tasktracker
```

**ДЗ2:**

```bash
cd dz2
make run-all
```

**ДЗ3:**

```bash
cd dz3
make run-all
```

ДЗ2 и ДЗ3 используют одни и те же порты: `50051` для gRPC и `8080` для HTTP. Одновременно запускать их на стандартных портах не получится.

**ДЗ4:**

```bash
cd dz4
createdb ozon_hw4
psql -d ozon_hw4 -f setup.sql
psql -d ozon_hw4 -f solutions.sql
```

`setup.sql` пересоздает учебные таблицы, поэтому его следует запускать в отдельной базе данных.

## Тестирование

Для ДЗ1–ДЗ3 проверки запускаются отдельно в каталоге каждого задания:

```bash
gofmt -l .
go test ./...
go build ./...
go vet ./...
```

Для ДЗ3 есть дополнительные команды для интеграционных тестов, проверки гонок и бенчмарков. Они описаны в [README ДЗ3](./dz3/README.md).

Для ДЗ4 запросы можно выполнить через `psql` после создания тестовых таблиц. Подробности находятся в [README ДЗ4](./dz4/README.md).
